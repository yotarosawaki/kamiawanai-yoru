# かみあわない夜

雪山ペンションの婚活ツアーで、34歳・彼女いない歴＝年齢の「僕」が、妄想と勘違いで事件を作り出していく
『かまいたちの夜』風サウンドノベル。人は死なない。エンディングは全18種、1周およそ45分〜1時間。

## 遊び方
- `index.html` をブラウザで開くだけで遊べます（音はブラウザ内で合成しているので、音声ファイルは不要）。
- 確認用サーバー： `node tools/serve.js` → http://localhost:8123/
- 進み具合（既読・エンディング・しおり）はブラウザの localStorage に保存されます。

## ファイル構成
| パス | 中身 |
|---|---|
| `DESIGN.md` | 企画書：登場人物、真相、分岐、フラグ、**シナリオの書き方（DSL）** |
| `scenario/*.js` | シナリオ本文（共通ルート・各編） |
| `js/engine.js` | ノベルエンジン（表示、選択肢、セーブ、スキップ、エンディング記録） |
| `js/art.js` | 背景（canvasで生成）と人物シルエット（SVG） |
| `js/audio.js` | BGM・効果音（WebAudioで合成） |
| `js/data.js` | エンディング一覧、使える背景・人物・音のID |
| `tools/validate.js` | シナリオ検証（飛び先・未定義ID・長すぎる行・到達性・文字数） |
| `tools/simulate.js` | ランダム通しプレイで各エンディングまでの長さと行き止まりを調べる |

## シナリオを直すとき
1. `scenario/` のファイルを編集する（書式は `DESIGN.md` 第7章）。
2. `node tools/validate.js` と `node tools/simulate.js` でチェック。
3. 開発中は `index.html#scene=シーンID` で、そのシーンから直接始められます。
